This package is designed to estimate and test multilevel structural equation models using Model Implied Instrumental Variables. 

Full details of the method are published in: 
Giordano, M. L., Bollen, K. A., & Jin, S. (2022). Estimating and Testing Random Intercept Multilevel Structural Equation Models with Model Implied Instrumental Variables. Structural Equation Modeling: A Multidisciplinary Journal, 29(4), 584–599. https://doi.org/10.1080/10705511.2022.2028261
https://www.tandfonline.com/doi/abs/10.1080/10705511.2022.2028261
